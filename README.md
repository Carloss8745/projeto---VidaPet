# Sistema VidaPet

## Sobre o projeto

O Sistema VidaPet é um projeto acadêmico desenvolvido para uma clínica veterinária fictícia, com o objetivo de organizar informações e auxiliar no gerenciamento de consultas.

## Objetivo

Desenvolver um protótipo inicial utilizando a linguagem Java, aplicando conceitos fundamentais de programação.

## Tecnologias utilizadas

- Java JDK 21
- IntelliJ IDEA

## Funcionalidades do protótipo

- Consulta do horário de funcionamento.
- Consulta da capacidade diária de atendimentos.
- Verificação do funcionamento da clínica.
- Menu interativo com opções.

## Organização do projeto

- src/: contém o código-fonte Java.
- docs/: contém a documentação e o diagrama de casos de uso.
